# Etherana Coder

**Etherana Coder** is a privacy-first AI coding workspace for local-first development.

It is distributed through the official Etherana / GoAnon website, with downloads intended to be hosted through Cloudflare R2-backed release links.

## Privacy-first by default

The current clean base disables or removes default telemetry, 1DS transport, experimentation services, hardware-derived identifiers, remote extension gallery access, marketplace identity headers, update checks, Settings Sync, Remote Tunnel, online feedback submission, and external vendor help links opened by default.

## Network behavior

Etherana Coder is not a sandbox. Network activity can still happen through Git remotes, package managers, terminal commands, development servers, user-installed extensions, configured AI providers, language tooling, and debuggers.

For maximum privacy, use local models, reviewed local extensions, and trusted offline workflows.

## Extensions

The remote extension gallery is disabled in the privacy-first base. Recommended usage is to install trusted local `.vsix` files.

## Status

Etherana Coder is currently in privacy-first rebuild and product-polish phase. Next phases include branding, first-run experience, local model setup, packaging, website download flow, release signing, and QA.
